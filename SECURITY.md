# Security policy

This repository is a **local research / portfolio lab** for Unity IL2CPP architecture and a payload↔client protocol.

- Do **not** use it against online games or other people's software.
- Do **not** open issues requesting bypasses, paid-auth help, or live game offsets.
- Report accidental secret commits privately; rotate any leaked key immediately.

The lab build registers only neutral demo modules (`LabPing`, `LabConfigEcho`, `LabFrameStats`).
